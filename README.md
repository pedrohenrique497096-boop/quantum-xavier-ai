# Quantum Xavier Market AI

Scanner automático de mercado com Streamlit.

## Recursos
- Sinais de compra e venda
- Entrada, stop e alvo
- Gráfico do ativo
- Histórico de sinais abertos
- Histórico de sinais encerrados
- Win rate
- Forex, Ouro e Crypto

## Rodar localmente
```bash
pip install -r requirements.txt
streamlit run app.py
